# 자리

같은 자리에 최근 10년간 몇 번 새 가게가 들어왔고, 각각 얼마나 버텼는지 계산합니다. 업소마다 행정동을 붙이는 작업도 여기서 합니다.

## 실행

저장소 루트 `.env`에 인증키 두 개가 필요합니다.

```
SEOUL_API_KEY=서울 열린데이터광장 일반 인증키
JUSO_API_KEY=도로명주소 검색API 승인키 (business.juso.go.kr)
```

경쟁 축 공용 파일 `permits_base.csv`(드라이브 공유)를 `data/base/`에 풀어 둡니다.

```
python3 jari/collect.py     # 인허가 수집 + 지번마다 행정동 조회 (약 1시간, 다시 실행하면 이어서 함)
python3 jari/hemd.py        # 업소별 행정동(주소 기준) → data/seoul/permit_hemd.csv
python3 jari/fill_dong.py   # 공용 파일에서 행정동이 빈 업소를 주소 결과로 채움 → jari/dong_fill.csv
python3 jari/sites.py       # 자리 지표 → data/seoul/sites.csv, site_history.csv
```

가게 데이터는 공용 파일을 기준으로 씁니다(경쟁 축과 숫자를 맞추기 위해). `collect.py`가 받는 원본은 주소 조회에만 씁니다.
표준 라이브러리만 씁니다. 결과는 `data/`에 쌓이고 git에는 올라가지 않습니다.

## 데이터

| 데이터 | 제공 | 쓰는 곳 |
|---|---|---|
| `permits_base.csv` | 경쟁 축(`competition/permits_prep.py`) 공용 파일 | 가게 이력 전체. 폐업 업소·모든 업태 포함 |
| 일반음식점·휴게음식점·제과점 인허가 (`LOCALDATA_072404`, `072405`, `072218`) | 서울 열린데이터광장 Open API | 지번 목록을 뽑아 주소 조회 |
| 실시간 주소정보 조회(검색API) | 행정안전부 도로명주소 개발자센터 | 지번 → 행정동 |

## 규칙

- **자리** = 같은 지번(구 동 번지). 층·호는 구분하지 않습니다.
- **같은 가게 합치기**: 같은 자리, 같은 상호, 폐업 30일 전 ~ 폐업 후 90일 안에 다시 인허가 → 한 가게. 주인 변경이나 업종 전환 때 관리번호가 새로 나와서입니다. 기준을 정한 근거는 아래 '확인했지만 그대로 둔 것' 참고.
- **폐업일 없는 폐업 업소**: 상태가 폐업인데 폐업일이 비어 있는 업소(31곳, 1980~2000년대 초 허가)는 언제 닫았는지 몰라 뺍니다.
- **행정동**: 공용 파일의 좌표 기준 행정동을 먼저 쓰고, 비어 있으면 주소로 찾은 행정동으로 채움. 주소 조회는 지번 → 안 되면 도로명주소 순. 행정동 이름은 `competition/dong_area.csv` 기준표의 코드로 맞춤. 행정동 경계에 걸친 지번(주소 API가 동을 여러 개 줌)은 같은 지번의 다른 업소들이 좌표로 받은 행정동 중 가장 많은 것으로 채움 (54곳)
- **여러 점포 건물**: 최근 10년 최대 동시 영업 수가 2 이상인 자리. 인허가 건수를 동시 영업 수로 나눈 한 칸당 횟수로 비교합니다.

## 결과 파일

`permit_hemd.csv` (업소 한 줄): 관리번호, 지번 키, 구, 행정동, 찾은 방법(`jibun`·`road`·`coord`·`none`)

`dong_fill.csv` (업소 한 줄): 공용 파일에서 행정동이 빈 업소 중 주소로 찾은 것. `source`, `mgt_no`, `adm_cd`, `adm_nm`, `gu`, `via`

## 서울 전체 결과 (2026-10-12 수집)

- 공용 파일 703,315곳 중 행정동이 빈 65,177곳에서 28,828곳을 주소로 채움 (영업 중 빈칸 12,032곳 중 11,092곳)
- 좌표·주소 두 방식이 모두 있는 589,439곳 중 98.8%가 같은 행정동. 다른 곳은 대부분 바로 옆 동(경계)
- 최근 10년 영업한 자리 111,672곳, 98.1%에 행정동. 57%가 단독 점포, 43%가 여러 점포 건물
- 단독 자리 평균 0.64건, 4건 이상 바뀐 자리 367곳 (0.6%). 예: 중구 황학동 479 (10년 9번, 황학동 평균 0.64)

## 한계

- 인허가가 필요한 음식점만 보입니다. 옷가게·편의점 같은 일반 소매는 데이터에 없습니다.
- 상호까지 바뀐 주인 변경은 새 가게로 셉니다.
- 재개발로 지번이 바뀐 곳은 옛 지번과 새 지번이 다른 자리가 됩니다. 건물이 새로 지어진 경우라 따로 보는 게 맞다고 판단했습니다.

## 확인했지만 그대로 둔 것 (참고용)

결과에 미치는 영향이 작아 방식은 바꾸지 않았습니다. 나중에 다시 볼 때 참고하도록 확인한 숫자를 남깁니다. (2026-10-14 확인)

### 1. 같은 가게 합치기의 30일·90일 기준

이전 가게 폐업일을 기준으로, **폐업 30일 전부터 폐업 후 90일 사이**에 같은 자리·같은 상호로 새 허가가 나면 한 가게로 봅니다.

- **30일 전**: 데이터에 근거가 있습니다. 같은 자리·같은 상호의 새 허가가 폐업 1~30일 전에 난 경우는 2,062건인데, 31~90일 전은 195건으로 뚝 떨어집니다. 30일 안쪽은 서류 처리가 겹친 것으로 봅니다.
- **90일 후**: 판단으로 정한 값입니다. 폐업 후 31~90일 4,269건, 91~180일 2,329건, 181일~1년 2,918건으로 서서히 줄어 뚜렷한 경계가 없습니다.
- **기준을 바꿔도 결론이 같습니다.**

| | 60일 | **90일 (사용)** | 180일 |
|---|---|---|---|
| 같은 가게로 합친 건수 | 22,764 | 24,290 | 26,592 |
| 단독 자리 평균 | 0.64건 | 0.64건 | 0.64건 |
| 4건 이상 바뀐 단독 자리 | 370곳 | 367곳 | 366곳 |
| 교체 건수가 바뀐 자리 (90일 대비) | 183곳 (0.2%) | - | 277곳 (0.2%) |
| 동네 순위 상관 (90일 대비, 1이면 동일) | 0.9998 | - | 0.9996 |
| 황학동 479 | 9건 | 9건 | 9건 |

- 상호가 같고 업태만 바뀐 경우(약 1만 3천 건)도 합칩니다. 대부분 커피숍 → 기타, 기타 휴게음식점 ↔ 백화점처럼 세부 분류만 바뀐 경우라 같은 가게로 봅니다.

### 2. 폐업 신고 없이 문 닫은 가게 ('영업 중'으로 남은 기록)

인허가 데이터는 폐업 신고를 해야 '폐업'으로 바뀌어서, 신고 없이 문을 닫은 가게는 '영업 중'으로 남습니다. 소상공인시장진흥공단 상가(상권)정보(2026-06 기준, 서울 55만 곳)와 같은 지번·같은 상호로 대조해 규모를 확인했습니다.

| 개업 시기 | 영업 중 기록 | 상가정보에 상호까지 일치 | 그 지번에 가게가 하나도 없음 |
|---|---|---|---|
| 2021년 이후 (기준선) | 69,139 | 63.1% | 3.9% |
| 2006~2015 | 31,556 | 69.2% | 6.2% |
| 1996~2005 | 17,832 | 68.9% | 11.1% |
| 1995년 이전 | 9,579 | 64.2% | 17.1% |

- 오래된 기록도 대부분 실제로 있는 가게입니다. 일치율이 최근 가게와 비슷합니다(상호 표기 차이로 최근 가게도 63%만 일치).
- 다만 오래될수록 지번에 가게가 아예 없는 기록이 늘어납니다. 재개발로 건물이 없어진 곳(예: 종로구 교북동·청진동)이 많습니다. 2005년 이전 개업한 영업 중 기록의 **약 9%(약 2,500곳)** 가 이런 경우로 추정됩니다.
- 그래서 "10년간 새 가게가 안 들어온 자리"는 "오래 영업한 자리"가 아니라 "음식점 인허가 기록상 새 가게가 들어오지 않은 자리"로 읽어야 합니다.

**큰 문제가 되지 않는 이유**

| | 지금 | 이런 자리를 뺐을 때 |
|---|---|---|
| 서울 단독 자리 평균 | 0.64건 | 0.67건 |
| 황학동 단독 자리 평균 | 0.64건 (216곳) | 0.77건 (181곳) |
| 경쟁 축 업종별 영향 | - | 한식 3.1%, 카페 1.9%, 제과점 1.4% |

- 서울 전체 결론은 거의 같습니다. 황학동 479(10년 9번)가 동네 평균보다 훨씬 자주 바뀐 자리라는 결론도 같습니다.
- 오래된 상권에 몰려 있습니다. 경쟁 축 기준으로 황학동 26%, 숭인2동 23%, 수서동 18%, 시흥3동 17%, 가락1동 14%가 이런 기록입니다. 이 동네들은 '지금 영업 중' 숫자가 실제보다 많게 나옵니다.
- 반영하게 되면 공용 파일 구조는 그대로 두고, `dong_fill.csv`처럼 "현재 영업 확인 안 됨 업소 목록"을 별도 표로 만들어 필요한 축이 가져다 쓰는 방식이 좋습니다.
