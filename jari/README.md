# 자리

같은 자리에 최근 10년간 몇 번 새 가게가 들어왔고, 각각 얼마나 버텼는지 계산합니다. 업소마다 행정동을 붙이는 작업도 여기서 합니다.

## 실행

저장소 루트 `.env`에 인증키 두 개가 필요합니다.

```
SEOUL_API_KEY=서울 열린데이터광장 일반 인증키
JUSO_API_KEY=도로명주소 검색API 승인키 (business.juso.go.kr)
```

경쟁 축 공용 파일 `permits_base.csv`(드라이브 공유)를 `data/base/`에 풀어 둡니다.

```
python3 jari/collect.py     # 인허가 수집 + 지번마다 행정동 조회 (약 1시간, 다시 실행하면 이어서 함)
python3 jari/hemd.py        # 업소별 행정동(주소 기준) → data/seoul/permit_hemd.csv
python3 jari/fill_dong.py   # 공용 파일에서 행정동이 빈 업소를 주소 결과로 채움 → jari/dong_fill.csv
python3 jari/sites.py       # 자리 지표 → data/seoul/sites.csv, site_history.csv
```

가게 데이터는 공용 파일을 기준으로 씁니다(경쟁 축과 숫자를 맞추기 위해). `collect.py`가 받는 원본은 주소 조회에만 씁니다.
표준 라이브러리만 씁니다. 결과는 `data/`에 쌓이고 git에는 올라가지 않습니다.

## 데이터

| 데이터 | 제공 | 쓰는 곳 |
|---|---|---|
| `permits_base.csv` | 경쟁 축(`competition/permits_prep.py`) 공용 파일 | 가게 이력 전체. 폐업 업소·모든 업태 포함 |
| 일반음식점·휴게음식점·제과점 인허가 (`LOCALDATA_072404`, `072405`, `072218`) | 서울 열린데이터광장 Open API | 지번 목록을 뽑아 주소 조회 |
| 실시간 주소정보 조회(검색API) | 행정안전부 도로명주소 개발자센터 | 지번 → 행정동 |

## 규칙

- **자리** = 같은 지번(구 동 번지). 층·호는 구분하지 않습니다.
- **같은 가게 합치기**: 같은 자리, 같은 상호, 폐업 30일 전 ~ 폐업 후 90일 안에 다시 인허가 → 한 가게. 주인 변경이나 업종 전환 때 관리번호가 새로 나와서입니다. 새 허가가 옛 허가의 폐업 신고보다 먼저 나는 경우가 있어 30일 겹침을 허용합니다.
- **폐업일 없는 폐업 업소**: 상태가 폐업인데 폐업일이 비어 있는 업소(31곳, 모두 1990년대 허가)는 언제 닫았는지 몰라 뺍니다.
- **행정동**: 공용 파일의 좌표 기준 행정동을 먼저 쓰고, 비어 있으면 주소로 찾은 행정동으로 채움. 주소 조회는 지번 → 안 되면 도로명주소 순. 행정동 이름은 `competition/dong_area.csv` 기준표의 코드로 맞춤
- **여러 점포 건물**: 최근 10년 최대 동시 영업 수가 2 이상인 자리. 인허가 건수를 동시 영업 수로 나눈 한 칸당 횟수로 비교합니다.

## 결과 파일

`sites.csv` (자리 한 줄)

| 컬럼 | 뜻 |
|---|---|
| `site_key` | 구 동 번지 |
| `gu`, `adm_cd`, `hemd_name` | 구, 행정동 코드(행안부 10자리), 행정동 |
| `permits_10y` | 최근 10년 새로 들어온 가게 수 |
| `max_concurrent` | 최근 10년 최대 동시 영업 수 |
| `per_slot_10y` | `permits_10y ÷ max_concurrent` |
| `closed_10y`, `avg_months_closed` | 최근 10년 폐업 가게 수, 평균 영업 개월 |
| `open_now`, `open_now_names` | 지금 영업 중인 가게 |
| `dong_avg_single` | 같은 행정동 단독 자리들의 평균 `permits_10y` |
| `dong_avg_per_slot` | 같은 행정동 전체 자리의 평균 `per_slot_10y` |

`site_history.csv` (가게 한 줄): `site_key`, 관리번호(합쳐진 경우 여러 개), 상호, 업태, 개업일, 폐업일, 영업 개월

`permit_hemd.csv` (업소 한 줄): 관리번호, 지번 키, 구, 행정동, 찾은 방법(`jibun`·`road`·`coord`·`none`)

`dong_fill.csv` (업소 한 줄): 공용 파일에서 행정동이 빈 업소 중 주소로 찾은 것. `source`, `mgt_no`, `adm_cd`, `adm_nm`, `gu`, `via`

## 서울 전체 결과 (2026-10-12 수집)

- 공용 파일 703,315곳 중 행정동이 빈 65,177곳에서 28,828곳을 주소로 채움 (영업 중 빈칸 12,032곳 중 11,092곳)
- 좌표·주소 두 방식이 모두 있는 589,456곳 중 98.8%가 같은 행정동. 다른 곳은 대부분 바로 옆 동(경계)
- 최근 10년 영업한 자리 111,672곳, 98.1%에 행정동. 57%가 단독 점포, 43%가 여러 점포 건물
- 단독 자리 평균 0.64건, 4건 이상 바뀐 자리 367곳 (0.6%). 예: 중구 황학동 479 (10년 9번, 황학동 평균 0.64)
