# 안정성 축 — "이 동네에서 이 업종이 버티나"

서울 427개 행정동 × 업종 3개(카페·제과점·한식)의 **교체율·신규율·3년 생존율**을 계산합니다.
팀 공통 규칙(`docs/common-rules.md`)을 따릅니다: 공용 파일 하나, 기준일 2026-09-30, 업종 3개.

## 실행

```bash
pip install -r stability/requirements.txt          # pandas 만 필요

# 공용 파일을 드라이브에서 받아 data/base/permits_base.csv 에 둔다 (data/ 는 git 에 안 올라감)
python stability/build_stability.py                # 기준일 기본값 2026-09-30
python stability/build_stability.py --base-date 2026-09-30 --min-n 20   # 옵션을 직접 줄 때
```

결과 4개는 `stability/data/`에 쓰이고, 이 폴더만 커밋합니다.

## 입력

| 파일 | 내용 |
|---|---|
| `data/base/permits_base.csv` | 팀 공용 파일 (`competition/permits_prep.py`, 2026-10-13 원본). 업소 키 `source + mgt_no`, 행정동 `adm_cd` |
| `competition/dong_area.csv` | 서울 행정동 기준표 427개 (`adm_cd` 10자리, `adm_cd8`, `adm_nm`, `gu`) |

## 공통 규칙 적용

| 규칙 | 안정성 축에서 |
|---|---|
| 1 공용 파일 | `permits_base.csv`만 씀. 따로 수집한 API 데이터는 쓰지 않음 |
| 2 기준일 9/30 | 9/30 뒤 인허가는 뺌. 9/30 뒤 폐업한 가게는 9/30에 영업 중으로 셈 |
| 3 업종 3개 | `category` 열(카페·제과점·한식). 빈칸은 쓰지 않음 |
| 4 폐업일 없음 | `close_date_missing`이면 **모든** 계산에서 뺌 (신규_1년 포함 → 분자·분모가 같은 묶음) |
| 5 팝업 | `is_temp`면 뺌. 다시 판정하지 않고 열을 그대로 씀 (판정 함수는 `temp_rule.py`, 공용 파일 만들 때 사용) |
| 6 주인 변경 | 합치지 않음. 관리번호 단위 |
| 7 구 평균 | **지표마다 따로** — 교체율·신규율은 `영업중_기초`, 3년 생존율은 `3년_코호트`가 20곳 미만이면 그 지표만 같은 구 값 |

## 설계 결정 (발표 Q&A 대비)

- **생존율을 '평균 영업기간'이 아니라 비율로** — 폐업 업소만 평균 내면 영업 중인 가게가 빠져 짧게 나옵니다. 개업 후 3년이 충분히 지난 코호트만 봅니다.
- **코호트를 8~3년 전 개업으로 제한** — 오래된 개업분까지 넣으면 '살아남은 노포'만 남아 생존율이 부풀려집니다.
- **교체율 분모는 1년 전 영업 업소 수** — 기간 시작 시점 기준이라 연중 신규 개업이 분모를 흔들지 않습니다. 교체율이 높다고 나쁜 동네는 아니라서 신규율을 항상 같이 보여줍니다.
- **팝업·행사 제외** — 공용 파일(기준일 9/30)에서 반포동 19-3 한 지번에만 3년간 인허가가 1,010건(모든 업태)이고, 그중 폐업분의 영업기간 중앙값이 12일입니다. 팝업을 빼지 않으면 제과점 교체율 1~3위가 잠실6동(113%)·반포4동(92%)·소공동(81%), 카페 1위가 삼성1동(47%)으로 나옵니다(빼면 반포4동 제과점 16%, 삼성1동 카페 12%). 판정은 `temp_rule.py`(공통 규칙 5).
- **영업상태** — 휴업은 영업 중. 취소·말소·정지 같은 행정처분은 창업·폐업 흐름과 달라 제외. 영업 중인데 폐업일이 찍힌 데이터 오류는 폐업일을 무시합니다(건수는 리포트).

## 한계

- **생존율이 공식 통계보다 높게 나옵니다**(통계청 「2015년 기업생멸행정통계」의 숙박·음식점업 3년 생존율 30.3%, 언론 보도로 확인. 더 최근 연도의 3년 생존율은 찾지 못함. 통계청은 사업자 단위라 정의가 다릅니다). 인허가는 영업자 지위승계 시 같은 관리번호로 이어지는 경우가 있어 '가게(자리)의 생존'에 가깝습니다.
- 행정동을 붙이지 못한 업소는 동 지표에서 빠지고 구·서울 지표에만 들어갑니다(건수는 `quality_report.json`).
- 인허가 기준이라 신고만 하고 실제로 열지 않은 업소가 섞일 수 있습니다.
