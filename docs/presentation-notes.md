## 2. 아키텍처 핵심

- **구성**: 화면(HTML·CSS·JS, Vercel) → FastAPI(Render) → PostgreSQL(Supabase, 서울 리전). 서비스 화면은 DB가 아니라 API를 부르고(데이터 분석 페이지는 미리 계산한 숫자를 담은 정적 페이지), DB 접속 정보와 API 키는 서버 환경변수에만 있습니다.
- **배치로 미리 계산**: 축별 Python 스크립트가 기준일(2026-09-30)로 지표를 계산해 DB에 넣고, API는 읽기만 합니다. 요청 때 계산하는 것은 비교용 값(구·서울 평균, 순위, 동별 자리 수)뿐입니다.
- **외부 API를 두 단계에서 씀**
  - 수집 단계: 서울 열린데이터광장 Open API(인허가 3종 `LOCALDATA_072404·072405·072218`, 지하철 시간대 `CardSubwayTime`), 도로명주소 검색 API(좌표 없는 가게의 행정동 찾기)
  - 서비스 단계(실시간): 주소 검색 `GET /api/address/search`가 요청 때마다 도로명주소 API를 불러 지번 → 자리·행정동을 찾습니다.
- **연결 키 하나**: 모든 축을 행안부 행정동 코드 10자리(`adm_cd`, 서울 427개 동)로 묶었습니다. 가게와 역 모두 같은 경계 파일(vuski/admdongkor ver20260701)로 좌표 → 행정동을 붙였습니다.

## 4. 시나리오와 주요 기능

**사용자**: 1~2인 규모로 창업을 준비하며, 계약 전에 후보지 서너 곳을 스스로 걸러 내려는 사람.

| 화면 | 하는 일 | 쓰는 API |
|---|---|---|
| 동네 비교 | 업종을 고르고 행정동 2~4곳을 네 축으로 나란히 비교. 종합 점수 없음 | `/api/dongs/compare` |
| 자리 상세 | 후보 주소를 넣으면 그 지번에 10년 동안 있었던 가게와 동네 평균을 보여 줌 | `/api/address/search` → `/api/sites/{id}` |
| 데이터와 기준 | 출처 9개·테이블 건수·지표 정의 | `/api/data/overview` |
| 데이터 분석 | 수집한 데이터 설명과 기초 분석 (과제 필수 페이지) | 정적 페이지 |

시연 예: "황학동 479" 검색 → 10년 새 가게 9곳, 황학동 단독 자리 평균 0.68곳.

**점수로 줄 세우지 않는 이유**: 좋은 자리는 업종과 사람마다 다릅니다. 교체율이 높아도 수요가 많아 계속 새로 들어오는 활발한 상권일 수 있어서, 교체율과 신규율을 항상 나란히 보여 줍니다.

## 7. 한계 (먼저 말하면 좋은 것)

- **행정동을 못 찾은 가게 467곳**: 기준일 영업 중 세 업종 71,880곳 중 467곳(카페 155, 제과점 16, 한식 296)은 어느 동네에도 들어가지 않습니다. 동네 합계는 71,413곳.
  - 원인: 467곳 모두 원본에 좌표가 없고, 도로명주소 API로 찾아도 445곳은 그 지번이 지금 없음(검색 결과 0건), 20곳은 번지가 없거나 형식이 깨짐, 2곳은 행정동 경계에 걸림.
  - 성격: 인허가 연도 중간값 1994년, 364곳(78%)이 2005년 이전. 중구 168곳·종로구 140곳으로 재개발 지역(청진동, 을지로7가 등)에 몰림. 대부분 폐업 신고 없이 닫은 기록으로 보이지만 하나씩 확인하지는 않았음.
  - 살리는 방법: 법정동 하나가 행정동 하나에 대응하는 곳은 법정동 이름으로 붙일 수 있으나, 공용 파일과 세 축을 모두 다시 계산해야 해서 하지 않음.
- **폐업 신고 없이 닫은 가게**: 인허가 데이터는 폐업 신고를 해야 폐업으로 바뀜. 상가정보와 대조하면 2005년 이전 개업한 영업 중 기록 27,432곳 중 약 4%(약 1,150곳)가 이런 경우로 추정 (`jari/README.md`).
- **3년 생존율이 공식 통계보다 높음**: 통계청 「2015년 기업생멸행정통계」 숙박·음식점업 3년 생존율은 30.3%. 우리는 사업자가 아니라 인허가(가게·자리) 단위라 정의가 다름.
- **수요는 역이 있는 동만**: 427개 동 중 225개 동. 버스와 생활인구는 쓰지 않음. 승하차는 타고 내린 인원을 더한 값이라 유동인구와 다름.
- **허가 연도가 이상한 기록**: 공용 파일에 1900년 허가 4건이 있음(자리 표시용 값으로 보임, 확인 안 함).
- **기준일 고정**: 9/30 이후 새로 생긴 가게는 반영하지 않음.

## 9. 검증 기록

- 배포된 API에서 무작위 16개 동 × 3업종 = 48건 리포트를 저장소 CSV와 대조: 경쟁(가게 수, 밀도), 안정성(교체율, 신규율, 3년 생존율, 구 평균 대체 동 포함), 동별 자리 수, 동별 역 수 모두 일치.

- 데이터 분석 페이지 숫자를 2026-10-17과 10-20에 다시 계산해 같은 결과.
